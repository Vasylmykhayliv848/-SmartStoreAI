# SmartStoreAI

## English

SmartStoreAI is an AI-powered e-commerce platform designed to help customers find products faster using natural language search and intelligent recommendations.

### Features

- 🤖 AI shopping assistant
- 🔍 Natural language product search
- 🛒 Smart product catalog
- 📸 Product image gallery
- 🏷️ Brand and category filters
- 💬 Product recommendations
- ⚡ High-performance C++ search engine
- 📱 Responsive user interface

### Example Queries

- Laptop for work and study
- Samsung under 30000 UAH
- iPhone up to 40000 UAH
- Gaming laptop with 16GB RAM

### Technologies

- C++
- HTML
- CSS
- JavaScript
- AI Integration

### Project Goal

The goal of SmartStoreAI is to simplify online shopping by combining AI-powered recommendations with fast product search and a modern user experience.

# SmartStoreAI

## Українська

SmartStoreAI — це AI-платформа для онлайн-магазину, створена для швидкого пошуку товарів за допомогою природної мови та інтелектуальних рекомендацій.

### Можливості

- 🤖 ШІ-консультант для покупців
- 🔍 Пошук товарів природною мовою
- 🛒 Розумний каталог товарів
- 📸 Галерея фотографій товарів
- 🏷️ Фільтри за брендом та категоріями
- 💬 Інтелектуальні рекомендації
- ⚡ Високопродуктивний пошуковий рушій на C++
- 📱 Адаптивний інтерфейс

### Приклади запитів

- Ноутбук для роботи і навчання
- Samsung до 30000 грн
- iPhone до 40000 грн
- Ігровий ноутбук з 16 ГБ оперативної пам'яті

### Технології

- C++
- HTML
- CSS
- JavaScript
- Інтеграція ШІ

### Мета проєкту

Мета SmartStoreAI — зробити онлайн-покупки швидшими та зручнішими за допомогою штучного інтелекту, інтелектуального пошуку та сучасного користувацького інтерфейсу.
